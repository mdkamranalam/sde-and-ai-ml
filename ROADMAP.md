# SDE + AI/ML Roadmap

This roadmap defines the major areas to study for becoming a Software Engineer capable of designing and building production-grade AI/ML systems.

The roadmap is intentionally broad. Completion should be based on understanding and practical implementation rather than simply checking boxes.

# Completion Standard

A topic should generally move through:

```text

Implement
    ↓
Practice
    ↓
Apply
    ↓
Document
    ↓
Explain
```
