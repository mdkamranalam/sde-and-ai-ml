# Resource Evaluation Criteria

Before relying on a resource, consider:

- Authority
- Technical accuracy
- Recency
- Depth
- Practical usefulness
- Primary-source availability

For technical behavior, prefer primary sources such as:

- Official documentation
- Specifications
- Research papers
- Source code
- Official engineering documentation
