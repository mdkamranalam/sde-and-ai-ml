# Architecture Decision Records

Architecture Decision Records (ADRs) document significant technical decisions.

An ADR should be created when a decision:

- Has meaningful architectural consequences.
- Has multiple reasonable alternatives.
- Is difficult to reverse.
- Affects scalability, reliability, security, or maintainability.
- Is useful for understanding why a system was designed a certain way.
