# Learning Strategy

The purpose of this document is to define how topics in this repository are studied, implemented, practiced, and reviewed.

---

# 1. Learning Cycle

The default learning cycle is:

```text
Learn
  ↓
Understand
  ↓
Implement
  ↓
Practice
  ↓
Experiment
  ↓
Apply
  ↓
Document
  ↓
Revise
  ↓
Explain
```
