# Technical Glossary

A continuously maintained glossary of important terminology encountered during the SDE + AI/ML learning journey.

---

## A

### API

Application Programming Interface.

A defined interface through which software components communicate.

### ACID

Properties commonly associated with reliable database transactions:

- Atomicity
- Consistency
- Isolation
- Durability

### Agent

An AI system capable of using tools or taking actions toward a goal rather than only producing a direct response.

---

## B

### Backpropagation

An algorithm used to calculate gradients of a neural network's loss with respect to its parameters.

### Big-O

A notation used to describe an algorithm's asymptotic growth rate.

---

## C

### Cache

A faster storage layer used to reduce the cost or latency of retrieving frequently accessed data.

### CNN

Convolutional Neural Network.

A neural-network architecture commonly used for spatial data such as images.

---

## D

### Dependency Injection

A software design technique in which an object's dependencies are provided externally rather than constructed internally.

### Docker

A platform for packaging and running applications in containers.

---

## E

### Embedding

A numerical vector representation of data such as text that attempts to encode semantic or other useful relationships.

---

## F

### Feature

An input variable used by a machine-learning model.

### Fine-tuning

Training an existing model further on a specific dataset or task.

---

## G

### Gradient Descent

An optimization algorithm that iteratively adjusts model parameters in a direction intended to reduce the objective function.

---

## H

### HTTP

Hypertext Transfer Protocol.

An application-layer protocol used for communication between clients and servers.

### HLD

High-Level Design.

Focuses on system architecture and interactions between major components.

---

## I

### Idempotency

A property where repeating an operation produces the same intended result as performing it once, within the relevant system semantics.

---

## J

### JVM

Java Virtual Machine.

The runtime environment that executes Java bytecode.

---

## L

### LLM

Large Language Model.

A model trained to process and generate language.

### LLD

Low-Level Design.

Focuses on classes, interfaces, relationships, and implementation-level design.

---

## M

### Microservices

An architectural approach in which an application is composed of independently deployable services.

### Model Drift

A change in the relationship between model inputs and the target behavior that can degrade model performance.

---

## N

### Normalization

A database design technique used to organize relational data and reduce undesirable redundancy and anomalies.

---

## O

### Overfitting

When a model learns patterns specific to training data that do not generalize well to unseen data.

---

## P

### Precision

For a classification setting, the proportion of predicted positive instances that are actually positive.

### Prompt

Input instructions or context provided to a generative model.

---

## R

### RAG

Retrieval-Augmented Generation.

A system architecture where relevant external information is retrieved and provided to a generative model as context.

### Redis

An in-memory data store commonly used for caching and other low-latency workloads.

---

## S

### SQL

Structured Query Language.

A language commonly used to work with relational databases.

### Spring Boot

A Java framework designed to simplify development and deployment of Spring applications.

---

## T

### Transformer

A neural-network architecture based heavily on attention mechanisms.

### Token

A unit of text processed by a language model.

---

## V

### Vector Database

A database or search system designed to store and retrieve vector representations using similarity-based search.

---

## W

### WebSocket

A protocol that enables persistent, bidirectional communication between a client and server.

---
